Portal Inspector & Recorder

A portable Windows tool that opens any web portal in a Playwright browser so you can inspect page components and record a workflow. The default portal is the JSW Ariba sourcing site; change the URL in the app for any other page.

How to use

  1. Extract the whole zip into a writable local folder.
  2. Double-click Start-Here.hta (or Start-App.bat if it is blocked). The first run needs internet to fetch Node.js, packages and Chromium.
  3. In the app, enter the portal URL, log in yourself, then inspect or record.

It runs only on your PC, at 127.0.0.1. This page just hosts the download; no portal data is sent here.

Use only on systems you are authorized to access. The read-only guard is best-effort and cannot guarantee every portal action is harmless. Never share credentials, and review recordings (they may contain session tokens and internal data) before sharing them.
